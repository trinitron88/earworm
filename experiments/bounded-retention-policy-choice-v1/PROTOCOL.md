# Bounded retention policy choice — frozen plan

Authoritative assignment: [PM instruction 5843842158](https://github.com/trinitron88/earworm/pull/2#issuecomment-5843842158), version 1. Base `f93977b000e59ee9b7d8bcc6092510b156bd77de`. Historical evidence is immutable.

## Decision and scope

Choose the simplest adequate clean-observation retention policy among FIFO, fixed-seed uniform reservoir, and streaming diversity. An unpressured reference and a present-only control are not selectable. These are exact note observations with **supplied occurrence/event segmentation**. The assignment requires complete occurrence records; this study neither discovers those boundaries nor tests audio, human perceptual identity, polyphony or an information upper bound.

All numerical settings are in `configuration.json`. Twenty-four fresh excerpt/motif families comprise four development, four calibration and sixteen evaluation families, balanced by Bach and project-generated material. Pieces stay disjoint across this study's splits and historical evaluation works remain evaluation. Bach works themselves were used historically: freshness means nonoverlapping, nonequivalent twelve-event excerpts, not unseen compositions. Source selection is chronological and structural, independent of candidate performance. The material inventory records exclusions and provenance. No newly acquired source is needed if this fixed local inventory passes construction.

A source arrives once, then exactly 128 four-second interference slots from other same-split frozen families/foils, then a return/query. This length is fixed before any candidate exposure, exceeds the 64-second requirement, and gives reservoir admission opportunities without outcome-conditioned extensions. Source/query identity, family, transformation and archives never enter retention. Four base streams per family (unchanged, nonzero integer pitch translation, uniform 0.8/1.25 stretch, unrelated foil) supply seven readout cells, including separate fresh source-removal readouts for all three positives. Each policy starts empty for each readout. Shared immutable evaluator inputs are not a cross-session predictor cache.

## Evidence arrival and bounded memory

The broker sends one completed second at a time, with clipped exact events and edge flags. Complete-record boundaries are supplied only when their last event has arrived, padded to completed integer units. The worker reconstructs the occurrence solely from its actual four-unit recent ring. All occurrences, including the eventual query, receive the same admission treatment. A decision signal arrives after the last required query unit; it carries no answer. Empty units advance and destructively evict recent observations. No accelerated simulation timestamp is represented as real-time playback.

Persisted records contain exact events, temporal support, an arrival ordinal and a fixed descriptor. Absolute pitches, note timing and rests remain available. FIFO removes the oldest. Reservoir uses standard Algorithm R, seed 202609260701, sampling admission **before insertion**: rejected incoming items never overflow the retained store. Every admitted ninth item replaces a stored item. Incoming rejections and actual old-record replacements are logged separately; rejections do not count toward twelve required replacements. No reseeding, extension or relabeling is permitted if the replacement gate fails.

Diversity uses eleven signed pitch intervals divided by twelve, plus globally normalized onsets and offsets. Distance is mean squared pitch difference plus weight 1 times mean squared timing difference. Among each prospective nine-record set, evict the record whose deletion maximizes the minimum distance between the eight survivors; ties choose oldest arrival then stable content hash. Identical or constant-pitch records are valid; nonpositive span, wrong event count, nonfinite or overlapping events are INVALID. This is a fixed rule, not a learned policy. The calibration grid has the singleton weight 1 and the unchanged unique-window abstention rule; calibration checks them without fitting or selecting a more favorable setting.

Capacity is eight complete records and 256 KiB of all persistent predictor state. The unpressured control has a separate 512-record/8 MiB cap. The four-second recent ring, transient matching arrays, peak RSS and outputs are counted separately. No persistent archive is accessible to the child. Filesystem and network access are disabled after module loading. Ledgers are emitted to the evaluator and not retained or re-read by the predictor. State-size accounting includes descriptors, ordinal/RNG state, indexes and Python containers; copies used for matching are separately reported scratch and released.

Source removal deletes source-overlapping persistent and recent evidence before rebuilding the matching input, descriptors/indexes and candidate lookup. Removed support is evaluator-selected intervention data, not an input to G. A match centered there is an integrity failure. Independent validation compares surviving event values with original arrived observations and verifies source absence, storage and replacement ledgers.

## Frozen correspondence and uncertainty

`global_matcher.py` is copied byte-for-byte from PR20 and invoked with `exact=True`. Its ranges remain pitch -5…+5 and time scale 0.65…1.5. Its last-two-second query rule remains unchanged: typically the sampled endpoint support is 1.9 seconds. **Complete twelve-event storage does not imply complete-phrase matching.** Partial-query alternatives may remain even with exact timing.

The original acceptance flag is preserved: exactly one consistent window accepts, more than one abstains. Every returned window and its mapped retained occurrence is saved. Compatible record-set containment, set size, candidate count, unique accepted identity, shift, scale, localization and abstention are separately scored. Multiple candidate windows are not silently collapsed into a successful unique origin. Complete occurrence equivalence is independently evaluated from all twelve pitch/onset/offset relations. Near matches on the short query stay alternatives. No arbitrary representative of an equivalent origin set counts as unique success.

## Scoring and branch precedence

All sixteen evaluation families stay in each denominator. Primary positive success requires the frozen matcher to accept one candidate mapped to an independently compatible complete prior occurrence. Joint pitch must be exact; joint scale must be within 10%. Report the stricter stipulated-source result and full-set containment separately. An abstention is visible and is not counted as a positive gate success. Incorrect acceptance counts even if its window lies near an expected source. Any accepted source-removal substitute counts toward the refusal gate.

Per selectable policy require at least14/16 identity, joint pitch and joint scale successes **in each** of the three positive cells, at most1/16 foil acceptance, at most2/48 source-removal acceptances, actual source eviction from the recent buffer, persistent capacity compliance and at least12 actual replacements in every scientific stream. Report both strata, all families, uncertainty and continuous localization errors. Present-only recurrence is reported and cannot qualify.

INVALID takes precedence for construction, execution, integrity, resource or incomplete evidence failures. Otherwise, if the unpressured reference fails any scientific gate, Result C withholds a retention conclusion. If that reference passes and a bounded policy passes every gate, Result A selects the first in FIFO/reservoir/diversity order. Otherwise Result B rejects these three tested policies. No outcome authorizes repair, capacity change, new policy, audio follow-up or another experiment.
