## Listener and borrowed methods

Both audio routes receive identical successive one-second float32 PCM chunks at 24 kHz. No group, note, phrase, source boundary, transformation, event list or score enters the audio child. A decision request after final audio is common to all routes. Query selection is fixed: the last twenty .1-second bins ending at the final observed RMS >1e-4 bin (minimum twelve bins required). Thus retrieval uses a recent two-second fragment, not a supplied whole-query segment. Earlier candidates must have extraction-unit context strictly before the first query unit. Alignment never spans a hole in remaining history.

1. Standard route: .1-second Hann/4096-point FFT, nearest-semitone power aggregation over MIDI 24–104, pitch-class folding, L1 normalization, CENS quantization at .05/.1/.2/.4, trailing five-frame Hann smoothing, L2 normalization. This is an explicitly disclosed FFT/trailing-smoothing variant of [AudioLabs CENS](https://www.audiolabs-erlangen.de/resources/MIR/FMP/C7/C7S2_CENS.html), not the original filterbank implementation. [FMP subsequence DTW](https://www.audiolabs-erlangen.de/resources/MIR/FMP/C7/C7S2_SubsequenceDTW.html) uses cosine costs and unweighted (1,1)/(1,2)/(2,1) steps, exact subsequence initialization, and accumulated cost divided by query rows. Its skipped anchors are not charged; a low cost is not exhaustive evidence coverage. Search shifts -5…+5; no octave/tritone claim.
2. Frozen local MERT: strictly loaded unchanged HuBERT-compatible checkpoint, CPU/four threads, no training/download. Exactly two candidates are declared before development: layers 6 and 12, each fractionally integrated into ten equal-duration rows per completed second. The nominal row bins do not imply narrow receptive fields: every row depends on its full completed second. Native MERT coordinates use the same cosine subsequence DTW without coordinate rolling. MERT correspondence is feature-only; shift estimation uses sidecar-derived chroma along the chosen path. Therefore this route is explicitly **MERT/sidecar hybrid**. MERT transposition invariance is tested, never assumed.
3. Clean score ceiling: a separate score-only child receives absolute-pitch one-hot rows (128 pitches plus silence) at .1-second centers, with the same unit timing, FIFO storage policy, query selection and DTW/shift search. It never supplies score data to the audio child. This retains an explicit relative/temporal matching control under clean observation, not an audio-only result.

Every route reports the single unconstrained minimum-cost match, then rejects if query/history span ratio is outside [.65,1.5]. It does not backfill a second-best duration-valid path. This deliberately simple borrowed readout may fail due to its query window, alignment or duration rule; such failure does not prove absent information in the encoder. Shift is history-to-query sign. Stretch is query-bin span / matched-history-bin span. Scores are uncalibrated distances, not probabilities.

## State, sidecar and controls

The recent raw ring contains at most four one-second chunks. Source PCM must actually be absent before query. Persistent admission is FIFO, maximum sixty completed one-second records; no target pinning. The entire joint candidate state, including both MERT layers, standard features, sidecar, timestamps, dictionaries and arrays, is conservatively charged against 8 MiB (stricter than counting one route alone). No session is long enough to force this sixty-second policy to replace records: report zero pressure honestly. Fixed weights, peak RSS and temporary serialization/alignment arrays are separate resident/scratch resources, not a hidden persistent allowance.

The shared sidecar contains unnormalized 81-bin log-frequency spectral power (frequency axis logarithmic, amplitude not log-compressed), absolute RMS and exact time/unit coordinates. Standard matching uses chroma derived from these powers; MERT uses them only for transformation estimation. All sidecar/index/state edges are included in each ablation. Independent evaluator code reconstructs power and RMS from archived PCM; tolerance is relative 1e-6 with denominator floor 1e-20. Exact frame/unit support is checked. Original sample archives are evaluator-owned and inaccessible to the guarded listener; Python file/network access is denied after model initialization. This is an auditable process/API isolation boundary, not an adversarial OS sandbox claim.

For each session/route measure full, recent-only (last four arrived units), and source-removal. Removal discards every complete unit whose one-second context intersects the evaluator-defined source interval, covering context outside nominal source bins. No identity/removal label reaches prediction. Smoothing/indexes are recomputed from remaining rows. `finish` clears live extraction records and raw ring before sanitized readouts. The next independent session resets; model weights alone persist. No cross-session feature reuse. Safe reuse means evaluator delivers only that condition's remaining arrived measurements for a readout, never source audio replay.

Actual monotonic send/receive/serialization/commit times and context sample indices are recorded. Conservative simulated real-time availability follows A_i=max(unit_end,A_previous)+measured complete chunk roundtrip. Decision latency is max(0,A_last-query_end)+readout roundtrip, including within-unit wait and any post-query padding. All ten MERT rows share completed-unit availability. Do not backdate nominal row timestamps as availability. Each condition is an independent readout at the same decision time, not nine serial real-time decisions. Responses are flushed/fsynced before each corresponding label record is written.
