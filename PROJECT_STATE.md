# Project Earworm

Earworm investigates representations and memory that let an auditory past help interpret current sound without replacing observations with expectations. The long-term goal is music listening and interpretation. Current synthetic experiments do not establish human appreciation or perceptual identity.

## Current phase

The fundamental-observation repair is complete and awaiting external review. **Result A on the bounded supplied-note task:** the new waveform-periodicity adapter plus unchanged simple retrieval predicts all 48/48 held-out continuations in each of four rendering cells. The old adapter predicts 36/48 when timbre changes. Joint gain is 25 percentage points, paired 95% CI 8.3–41.7 points. The pure/fundamental-dominant octave-safety guard and all causal/control gates pass.

Only the observation step changed for the primary comparison. Retrieval order, cutoff, probability parameters and historical source/config remain fixed. Other strong simple mechanisms also pass when given the repaired observations; no relational-superiority claim follows. Clean monophonic tones, supplied boundaries, short memory and a small fractional-factorial design remain limitations.
