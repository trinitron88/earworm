# Project Earworm

Auditory representation and memory experiments.

This private repository starts with a sanitized review snapshot of **Experiment 08: Competing accounts**, completed September 19, 2026. It is a handoff for review, not a new experiment or a deployment.

Start with [PROJECT_STATE.md](PROJECT_STATE.md) for evidence, limitations, source provenance, exact artifact paths, and reproduction commands. Download [the standalone report](outputs/competing-accounts-report.html) and open it in a browser for its five short synthetic audio examples; GitHub normally displays HTML as source.

The original execution had no recorded Git revision. This upload commit identifies the review snapshot only. The six frozen source hashes and protocol timestamps are preserved unchanged. No experiment was rerun or retuned for publication.

[Issue #1](https://github.com/trinitron88/earworm/issues/1) is the handoff thread. No automatic worker/reviewer loop is configured.
